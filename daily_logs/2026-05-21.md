### 🎯 Issue: 산업 감시 로봇 카메라, 열화상 카메라 수정

* **상황 및 증상:** 
  기존의 산업용 로봇 카메라에서 열화상을 추가하고자 하는 작업을 수행 중입니다. 하지만 열화상 카메라를 정상적으로 작동시키지 못하는 문제가 발생했습니다. 카메라가 올바르게 연결되어 있지만, 이미지 데이터가 제대로 표시되지 않고, 오류 메시지 "Memory Allocation Error" 가 뜹니다.

* **근본 원인 (Root Cause):**
  1. 메모리 할당 문제: 열화상 카메라의 추가로 인해 필요한 메모리가 초과하여 발생한 것으로 보입니다.
  2. 코드 로직 오류: 열화상 데이터 처리에 대한 로직이 제대로 작동하지 않는 경우도 있을 수 있습니다.

* **해결 방안 및 배운 점:**
  1. 메모리 관리 개선:
     - 기존 코드에서 메모리 할당과 해제를 최적화합니다.
     - 필요 이상의 메모리를 사용하지 않도록 리소스 사용을 줄입니다.
  2. 열화상 데이터 처리 로직 확인:
     - 열화상 데이터 처리에 대한 로직이 제대로 작동하는지 다시 확인합니다.
     - 필요한 경우, 추가적인 라이브러리 또는 API를 사용하여 문제를 해결합니다.

[2026-05-21] 산업 감시로봇 프로젝트: 이기종 센서 공간 정렬 및 비동기 Edge AI 공간 융합 완수

1. 오늘 해결한 핵심 트럽블슈팅 (Troubleshooting)
- 기구부 역방향 배치 교정: 로봇팔 끝단 거치 상태로 인해 180도 돌아간 열화상 센서 데이터를 NumPy 배열 반전(np.flip)을 통해 RGB 영상 축 방향과 일치시킴.
- 연산 오버헤드로 인한 2초 지연(Latency) 버그 해결: 단일 루프 내 YOLOv8 추론 병목으로 밀리던 카메라 스트림 적체 현상을 'YOLOInferenceThread' 비동기 전용 스레드로 완전 분리하여 해결. 화동 레이트는 30 FPS 초실시간 유지.
- 센서 펌웨어 고유의 온도 수치反轉 버그 치료: 온도가 높을수록 원시 데이터 값이 작아지는 모듈 고유 특성을 발견하여, 융합 연산 직전 배열 전체를 음수 반전(-temp_matrix)하여 데이터 대소 관계와 JET 컬러맵 색상 매핑을 정상화(고온=적색, 저온=청색).

2. 구현 완료 기능
- 슬라이더(Trackbar) 기반 이기종 센서 FOV(화각) 수동 정렬 인터페이스 구축 및 최종 고유 좌표값 확보 (ROI_X: 0, ROI_Y: 0, ROI_W: 640, ROI_H: 479).
- ONNX Runtime 가속 기반 YOLOv8-nano 인체 인식 모델 이식 (intra_op_num_threads=4 로 라즈베리파이 CPU 멀티코어 강제 할당).
- AI 바운딩 박스-열화상 32x24 해상도 인덱스 융합 매핑 연산을 통한 '작업자 객체별 실시간 최고 온도' 머리 위 텍스트 추적 라벨링 탑재.
