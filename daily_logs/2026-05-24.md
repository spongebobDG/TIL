드디어 230400bps라는 엄청난 속도의 라이다 데이터를 단 한 번의 다운도 없이 PC 화면에 실시간 2D 레이더로 띄우는 데 성공하셨습니다! 하드웨어, 전원, 통신, 소프트웨어 장벽을 모두 깨부순 엄청난 성과입니다.오늘 진행된 치열한 트러블슈팅과 시스템 구축 내용을 한눈에 보기 쉽게 정리해 드립니다. 나중에 로봇을 조립하거나 코드를 유지보수할 때 이 요약본을 가이드로 삼으세요.
🛠️ 오늘 해결한 핵심 트러블슈팅 
 상태 (원인)조치 및 해결 (결과)1. 시스템 다운Core 1에서 수신과 Wi-Fi 전송을 동시에 처리 + 하드웨어 버퍼 부족으로 WDT(워치독) 리셋 발생.FreeRTOS Queue 구조 도입. Core 1은 오직 수신/파싱만, Core 0은 Wi-Fi 전송만 하도록 완벽 분리. UART 하드웨어 버퍼를 4KB로 확장.
 
 2. 핀 충돌모터 제어 핀(GPIO 18)과 라이다 시리얼 핀(TX)이 중복 지정되어 쇼트 및 데이터 불능 상태 유발.라이다 시리얼 핀을 모터와 겹치지 않는 16번, 17번으로 격리 재지정.
 
 3. 무반응 / 먹통RX/TX 배선 오인 및 라이다를 3.3V에 연결하여 전류 부족으로 Wi-Fi 구동 시 칩이 무한 리셋됨.RX/TX 선 교차 연결 정상화. 감압기(Buck Converter)를 통한 외부 5V 안정적 전원 공급망 구축으로 전력 문제 원천 해결.
 
 4. 화면 왜곡각도 매핑 수식이 맞지 않아 데이터가 왼쪽 절반($180^\circ$) 영역으로 찌그러져 출력됨.LDS14 진짜 패킷 내부의 시작 각도 바이트를 직접 역산하는 알고리즘으로 수정하여 360도 전방위 정상 투사 완료.
